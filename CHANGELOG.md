# Changelog

## Recent Changes (unreleased)

### Account & AutoGift
- Added profile editing on account page (full name, phone).
- Added AutoGift onboarding wizard: first-time users are prompted for address, payment, and recipient details.
- AutoGift wizard shows once per user and can be retaken from the empty state.

### Boards & Submissions
- Board creation now requires login.
- Board visibility updated toward public-by-default behavior (see Boards page).
- Customers can submit products via URL; submissions go to admin for approval.

### Scoring
- Gift rating thresholds adjusted to be stricter (requires AI-side tuning).
